# 📱 Instagram Reels Product Teardown & Feature Proposal

[![Cover](assets/Cover.jpeg)](assets/Cover.jpeg)

A product management case study exploring how Instagram can activate zero-post Indian users to create their first Reel by reducing psychological friction and simplifying the creator journey.

---

## 📌 Overview

Instagram Reels has become one of Meta's fastest-growing products, but the majority of users still remain passive consumers rather than creators.

This case study identifies the reasons behind this behaviour through user research, journey mapping and competitive analysis before proposing product features aimed at increasing first-time Reel creation.

[![Overview](assets/Overview.jpeg)](assets/Overview.jpeg)

---

## 🎯 Problem Statement

Despite millions of daily Reels viewers, only a small percentage of Instagram users actively create content.

> **How might Instagram encourage zero-post Indian users to create their very first Reel?**
